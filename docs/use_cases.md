# Use cases

1. **Screen a listing.** Enter the form on the Predict page. The app returns a good-investment flag with probability, a 5-year price under the project rate table, and model-level feature importance.
2. **Slice the book.** The Explore page filters by state, city, BHK, type, and price, then shows the table plus city bars, size–price scatter, ₹/sqft boxes, and Year_Built trend.
3. **Audit the data.** The Insights page and `reports/figures/` show why location barely prices this file, and how the label tracks transport by design.
4. **Reproduce experiments.** MLflow (`mlruns/`) stores params, metrics, confusion matrices, and registered models so a later run can be compared without rerunning every baseline.

This tool is for a portfolio / teaching project. It is not a valuation, a buy recommendation, or a substitute for a site visit, title check, or local comparable sales.
